课表集控编辑

班级设置

id 只读：它就是线上目录名，也是客户端 {id} 的替换值，改了大屏立刻拉不到课表。
新班级先建成预留班级（只占 id、不下发空课表），选好默认作息后点「转为正式班级」再排课。

课表

行 = 上课节次（左侧为该节真实起止时间）；蓝线 = 作息里的分割线；留空 = 无课。周五等使用不同作息的日子会单独按其作息渲染。
周轮换：切到「第 N 周」后编辑某天，会自动把那天从「每周相同」复制一份拆成 day@N（未拆分的天仍跟随每周相同）；列头的 ↺ 可删掉该周特殊安排、合并回去。

作息表

上课 / 课间 需要起止时间；分割线 / 行动 是零长度标记，只有开始时间。
上课节数决定课表网格有几行 —— 增删「上课」项会改变所有用此作息班级的课表长度。
guid 是线上既有 GUID 的钉桩，只读：改它会让引用此作息的线上课表全部悬空（静默损坏）。

自定义科目

只在这里登记官方 21 科之外的科目。简称留空则自动取名称首字； 户外会让客户端按室外课处理（如天气提醒）。
科目名必须与课表里写的完全一致 —— 拼错会在构建时报错，而不是静默生成幽灵科目。

官方科目（只读，共 科）

官方科目的 GUID / 简称 / 户外属性由 ClassIsland 上游定义，本工具直接复用， 不抄进 yaml —— 抄一份就等于把它冻结在今天的值上，以后上游改了还在下发旧值。

客户端默认设置（DefaultSettingsSource）

这里配的是下发给客户端的默认设置。键名必须与 ClassIsland 自身的设置模型一致， 本工具不校验键名（做白名单只会拦住合法配置）。填错的键客户端会忽略。
留空 = manifest 不带 DefaultSettingsSource，客户端保留本机设置。
类型选 JSON 时值按 JSON 解析，可写数组或对象，例如 [1, 2, 3] 或 {"A": true}。

集控策略（policy）

策略下发后客户端本机对应功能会被锁住。 DisableEasterEggs 未见于官方文档，是实测得到的字段，可能随版本失效。

基本信息

组织名是客户端「集控信息」里显示的名字，与档案名相互独立。留空则回落到档案名。

发布地址（publish.base_url）

静态文件的公开访问根地址，通常是仓库的 raw 地址（注意分支名要对）。 客户端就是从 <base_url>/manifest.json 拉配置的。

装机预设 ManagementPreset.json

下载 ManagementPreset.json
放到客户端程序目录下，ClassIsland 启动时会自动加载集控配置，免去每台大屏手填服务器地址。 文件里的 ClassIdentity 留空 —— 每台大屏装好后填自己的班级 id（就是 URL 里 {id} 的值）。

首次使用向导 · 连接你自己的集控仓库

  1. 在 Gitee / GitHub 新建一个公开的空仓库，用来存放生成出来的配置（与本程序分开放）。
  2. 把仓库地址粘到下面，向导会自动 clone、识别默认分支并算出客户端访问的 raw 地址。
  3. 确认后发布地址会写进课表；之后在网页改课表点「发布到线上」即可。
  4. 客户端通过下载的 ManagementPreset.json 一键入控（在「基本信息」页）。
仓库必须公开：ClassIsland 客户端不带任何凭据去拉这些 JSON，私有仓库大屏会拉不到。 首次 clone 若需要登录，请用带令牌的 HTTPS 地址，或先在本机配好 git 凭据。

导入客户端导出的 Default.json

  1. 在 ClassIsland 客户端里导出课表档案 Default.json。
  2. 选择该文件，并填写它归属的班级 id（就是大屏集控里填的班级标识 / 线上目录名）。
  3. 导入后作息、科目的 GUID 会原样保留，可在网页继续编辑，再点「发布到线上」拆分推送。
相同 id 的班级会被这份档案整份覆盖（导入前会自动备份当前课表）。
叠加课表 / 临时课表不属于常规周课表，会被跳过并在结果里提示。
